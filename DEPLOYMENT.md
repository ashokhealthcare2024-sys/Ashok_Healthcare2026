# Deployment

## Static site upload

Upload `index.html`, `pages/`, and `assets/` to the hosting document root, preserving their paths. Configure the host to serve `404.html` as the not-found page where supported.

Search-engine verification and sitemap files are intentionally not included.

## Post-deployment checks

Open the homepage and each page in `pages/` on the canonical domain. Confirm that local images, stylesheets, scripts, the mobile menu, and the 404 page load correctly.
